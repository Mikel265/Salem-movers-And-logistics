# Salem Movers And Logistics — Production Website

A bold, modern, high-converting commercial website for **Salem Movers And Logistics**, based in Nakuru, Kenya, serving customers across Kenya.

## Technology Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS (Custom near-black & signal-yellow design system)
- **Typography:** Bebas Neue (Headlines) & Inter (Body & Controls)
- **Motion:** Framer Motion via `motion/react`
- **Icons:** `lucide-react`

## Key Features

- **High-Impact Hero Section:** Custom clamp headlines (`clamp(64px, 11vw, 150px)`), natural Kenyan relocation photography, and staggered entrance animations.
- **Signal-Yellow Benefits Strip:** Highlights Moving & Relocation, Fumigation & Pest Control, Services Across Kenya, and Convenient Enquiries.
- **Service Cards with Dynamic Pre-selection:** Clicking "Request Quotation" automatically scrolls to the quote form and pre-selects the chosen service, plus direct WhatsApp chat launch.
- **How It Works (01–04):** Editorial timeline showing the 4-step process from quotation request to job completion.
- **Why Choose Salem Movers:** Authentic split-layout highlighting careful handling, clear communication, and practical coordination without fabricated claims.
- **Coverage Section:** Emphasizes Nakuru base and nationwide reach across major Kenyan transport corridors.
- **Quotation Form & WhatsApp Handoff:**
  - Real-time Kenyan phone number validation (`07...`, `01...`, `+254...`).
  - Dynamic conditional fields based on service (Moving routes, Fumigation pest concerns, Storage duration).
  - Transparent WhatsApp handoff compiling form fields into a formatted message directly sent to `+254 728 856225`.
- **Floating WhatsApp Widget:** Unobtrusive, quick launcher for general quotes, residential moving, or fumigation.
- **SEO & Structured Data:** Semantic HTML5, meta tags, and verified `LocalBusiness` JSON-LD schema.

## Getting Started & Development

To run locally:
```bash
npm install
npm run dev
```

To build for production:
```bash
npm run build
```
The output will be generated in `dist/`.
